# EasyStart Integration

This is a custom Home Assistant integration for an EasyStart Bluetooth-enabled soft starter.

## Requirements

* Home Assistant
* HACS

## Installation

### Add this repository to HACS

[![Open your Home Assistant instance and add a repository to the Home Assistant Community Store](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=h4badger&repository=home-assistant-easystart&category=Integration)

### Download this integration in HACS

1. Go to HACS
2. Search for "easystart"
3. Click on the entry for this integration
4. Click "Download"
5. Restart Home Assistant

After restarting Home Assistant, when your air conditioner is running, the Bluetooth integration should discover the soft starter and allow you to add it.
